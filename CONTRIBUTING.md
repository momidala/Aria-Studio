# Contributing

This repository is part of the THerD platform. The canonical contributing
guide — spec-first workflow, testing tiers, DCO sign-off, license boundary —
lives in the platform repo:

https://github.com/momidala/THerD-platform/blob/master/CONTRIBUTING.md

Quick essentials: read the relevant SPEC-*.md before coding; every behavioral
change needs a test; all commits need `Signed-off-by` (`git commit -s`, DCO);
contributions are MIT inbound = outbound.
